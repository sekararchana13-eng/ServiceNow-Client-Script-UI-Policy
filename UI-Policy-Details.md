# UI Policy Details

## Table
Incident

## Purpose
To dynamically control Incident form fields based on Incident conditions.

## Conditions
The UI Policy uses Incident fields such as:
- State
- Category
- Priority
- Impact

## Field Behaviors
The UI Policy can control fields as:
- Mandatory
- Read-only
- Visible

## Expected Behavior
When the defined Incident condition is satisfied, the configured field behavior should be applied dynamically on the form.
